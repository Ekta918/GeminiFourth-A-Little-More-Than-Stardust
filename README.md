# GeminiFourth | A Little More Than Stardust ✨

A dreamy, interactive fan-made website dedicated to Gemini Norawit and Fourth Nattawat, celebrating their memorable series, individual projects, and journey on screen.

### 🌿 Features
- Elegant light theme with ivory, pistachio green, butter yellow, terracotta, and plum
- Animated hero section with floating decorations
- GeminiFourth story and appreciation section
- Project gallery featuring their shared series and individual projects
- Separate spotlights for Gemini and Fourth
- Interactive wish garden with floating stars, flowers, and hearts
- Animated sections and responsive mobile-friendly layout
- Fan appreciation letter

### 🎬 Featured Projects
- My School President
- Moonlight Chicken
- Our Skyy 2
- My Love Mix-Up!
- Ticket to Heaven
- The Dark Dice
- Scarlet Heart Thailand

### 💻 Built With
- HTML5
- CSS3
- JavaScript

### 🖼️ Images
Add your JPEG images to the same repository as `index.html`, using the filenames specified in the code.
